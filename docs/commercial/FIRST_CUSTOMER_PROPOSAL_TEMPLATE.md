# First Customer Proposal Template

Customer / background / objective; why ASA; agreed scope and approach; deliverables; tentative
schedule; customer responsibilities; assumptions; exclusions; fees and tax; retest treatment; start
conditions; proposal validity; next step. This proposal is not an SOW, MSA, NDA, or Authorization to
Test; legal/commercial wording requires completion and review.

Start conditions include commercial agreement, explicit scope, technical contact, appropriate test
environment, agreed access method, written Authorization, RoE, and GTM-2 readiness. Payment does not
authorize technical execution.
