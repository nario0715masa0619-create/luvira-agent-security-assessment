# SOW Input Template

Record customer legal name, engagement ID, product/environment, scope/explicit targets/exclusions,
third-party boundary, allowed test cases/families, write/production policy, credentials/access,
window, emergency contacts, deliverables, delivery method, timeline, fees/tax/payment inputs,
retest treatment, retention/deletion input, Authorization and RoE references. This is commercial and
technical input for qualified legal review, not contract language.
