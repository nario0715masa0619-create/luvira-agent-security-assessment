# First Customer Qualification

**Good fit:** B2B AI SaaS/Agent with tool/connector/action capability, enterprise-review pressure,
test/staging environment, technical contact, architecture disclosure, and possible written testing
authorization. **Poor fit:** generic web pentest, certification, destructive production testing,
unauthorized/third-party targets, managed remediation expectation, or refusal of scope constraints.

Outcome: **QUALIFIED**, **QUALIFIED_WITH_CONDITIONS**, or **NOT_QUALIFIED**.
