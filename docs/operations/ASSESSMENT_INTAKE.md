# ASA First-Customer Assessment Intake

Record customer/legal entity, product and system purpose, architecture, LLM/provider, agent
framework, RAG/memory, MCP, tools/connectors, permissions/credentials, data stores/external SaaS,
staging/production status, sensitive data, intended high-risk actions, existing controls,
constraints, and the enterprise/security requirement motivating assessment. Record unknowns as
questions; do not infer implementation facts.

This intake feeds: Intake → SOW/scope → Authorization → Rules of Engagement → Access Plan → Safety
Precheck → Readiness Checklist → Execution.
