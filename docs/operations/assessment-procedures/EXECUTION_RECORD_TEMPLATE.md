# Execution Record Template

Record engagement/execution ID, Test Case ID/version, executor, timestamp, target, precondition
status, result (`PASS`, `FAILURE_OBSERVED`, `INCONCLUSIVE`, `NOT_EXECUTED`, `STOPPED`), observed and
expected behavior, sanitized evidence references, safety events/STOP reason, notes, and Finding
Candidate reference. FAILURE_OBSERVED is not a confirmed Finding.

## AI Assistance

- AI assistance used: yes / no
- AI-assisted content type (if yes): intake or source summarization / risk hypothesis generation /
  observed behavior wording draft / finding candidate wording draft / report language draft / other
- AI output treated as candidate/draft only: yes / no / n/a
- Evidence check completed by human: yes / no / n/a
- Human review completed: yes / no / n/a
- Notes:

AI assistance is traceability only; it does not change the result or Finding Candidate status. See
[AI-assisted Assessment Controls](../AI_ASSISTED_ASSESSMENT_CONTROLS.md).
