# Assessment Data Retention and Deletion

For credentials, raw inputs/logs, screenshots/Evidence, Execution Records, Finding Candidates,
Canonical Findings/Assessment Record, report, and retest records, record purpose, minimum-necessary
handling, deletion trigger, and SOW/customer-agreement override per engagement. Do not assert an
arbitrary legal retention period: retain only as agreed/required and delete when no longer required.

Credentials require stricter treatment: approved secret mechanism before use, temporary access
revoked/deleted at closure, removal confirmation, no credential in artifacts, and incident handling
for exposure. Exact default retention periods remain commercial/legal decisions.
