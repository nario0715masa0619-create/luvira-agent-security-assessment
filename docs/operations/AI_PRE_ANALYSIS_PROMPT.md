# AI事前分析プロンプト

あなたは、AIセキュリティ診断の事前分析担当です。

以下は、AIサービス安全性チェックの事前ヒアリング回答です。

目的は、回答内容をもとに、
この企業・サービスに対して、どのような安全性チェックを行うべきかを整理することです。

重要：
この分析では、断定しすぎないでください。
回答内容だけでは判断できない点は「追加確認が必要」としてください。
実際の危険性を確定するのではなく、初回ヒアリングで確認すべきリスク仮説として整理してください。

また、以下の表現は使わないでください。

- 安全性を保証できる
- すべてのリスクを発見できる
- 必ず問題がある
- 必ず安全である
- 法的・認証上の合格を保証する

---

## 診断レベル分類

以下の3段階で分類してください。

### Level 1：AIアプリ利用レビュー

対象例：

- ChatGPT / Claude / Gemini / CopilotなどのAIアプリを社内利用している
- 既製AIツールを業務で使っている
- 外部サービス操作や独自AIシステムはない
- 主なリスクは、機密情報入力・共有設定・社内ルール未整備

主な確認項目：

- どんな情報をAIに入力しているか
- 顧客情報や社内機密を入力していないか
- AI利用ルールがあるか
- 履歴・共有・ファイルアップロードの運用が安全か
- 社員がAI出力をそのまま業務判断に使っていないか

---

### Level 2：AI API / RAG / 社内AIツール診断

対象例：

- OpenAI APIなどを使った社内ツール
- 社内文書検索AI
- FAQ AI
- 問い合わせAI
- 顧客情報や社内文書を参照するAI
- 外部操作は限定的、または存在しない

主な確認項目：

- AIが参照する文書・データ範囲
- ユーザーごとの閲覧権限
- 本来見えない情報がAI経由で見えないか
- 文書内の悪意ある指示にAIが影響されないか
- APIキー・ログ・出力に機密情報が残らないか
- AI出力が業務フローへどう使われるか

---

### Level 3：AIエージェント / 外部サービス操作あり診断

対象例：

- AIがSlack / メール / DB / CRM / API / カレンダー等を操作できる
- AIが外部サービスに投稿・更新・送信・登録できる
- AIが顧客データや社内データへアクセスする
- AIの判断が業務処理に直接影響する
- 顧客向けAIサービスとして提供されている

主な確認項目：

- AIが使える権限
- 連携している外部サービス
- 承認なしで実行できる操作
- Tool / API / 外部操作の範囲
- 外部入力や想定外の指示で意図しない操作が起きないか
- 顧客情報や社内情報へのアクセス範囲
- 操作ログ・承認フロー・停止条件
- 業務影響

以下を含めてください。

- 事前に用意してもらうもの

- 画面共有で確認すること
- ダミーデータで試すこと
- 初回レポートに含める内容
- 実施しないこと

---

## 9. 注意すべき安全上の制約

診断時に避けるべきことを整理してください。

必ず以下を含めてください。

- 本番管理者ID/PWを預からない
- 実顧客データを不要に取得しない
- 破壊的操作をしない
- 外部送信・削除・更新は事前承認なしに行わない
- ダミーデータを優先する
- 画面共有やスクリーンショットでは機密情報をマスキングする
- 安全性を保証する表現を避ける

- Level 1 AI利用レビュー

- Level 3 AIエージェント攻撃試験
- 現時点では対象外

理由も簡潔に書いてください。
